# Hospital Management System

## About the Project
The Hospital Management System is a menu-driven Python application developed using **Object-Oriented Programming (OOP)** and **File Handling**.

This project helps manage patient registration, doctor details, appointment booking, and medical records. All information is stored in text files for future access.

## Features
- Register new patients
- View patient details
- Search patients by ID
- Update patient information
- Delete patient records
- Add and view doctor details
- Book patient appointments
- View appointment details
- Maintain medical records
- Store and retrieve data using text files

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- File Handling
- Text Files (`.txt`)

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/your-username/hospital-management-system.git
```

2. Open the project folder:
```bash
cd hospital-management-system
```

3. Run the Python file:
```bash
python main.py
```
